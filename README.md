# Awesome-Conversational-Sms-Messaging

# Top Conversational SMS & Messaging Ecosystem

**Curated List of SaaS Products & Open-Source GitHub Projects**  
*Focused on Two-Way SMS, Omnichannel Inbox & Business Messaging*  
**Last updated: March 2026**

This repository tracks notable **SaaS platforms** and **open-source projects** for **Conversational SMS & Messaging**. These tools enable businesses to engage customers through two-way SMS, MMS, RCS, WhatsApp, and other messaging channels — supporting sales conversations, customer support, appointment reminders, and marketing campaigns at scale.

**Examples** include Salesforce Live Message, Twilio Messaging, Podium, SlickText, Attentive, EZ Texting, SimpleTexting, Birdeye, Klaviyo SMS, and SMS Magic (the category leaders).

**Open-source emphasis**: This section is heavily expanded with every major active project for self-hosting, custom SMS gateway integration, and open conversational platforms — ideal for businesses and developers seeking transparent, vendor-independent messaging solutions.

Contributions welcome! Open a PR to add/update entries. Keep descriptions factual and link to official sites.

## SaaS/Hosted Platforms

- **[Salesforce Live Message](https://www.salesforce.com/)**  
  Native Salesforce messaging solution enabling two-way SMS, WhatsApp, and Facebook Messenger conversations within Service Cloud. Features Einstein AI for agent assistance and case creation from conversations.

- **[Twilio Messaging](https://www.twilio.com/messaging)**  
  Programmable SMS, MMS, RCS, and WhatsApp API platform. Features global reach, intelligent sending, and extensive developer tools for building custom conversational experiences.

- **[Podium](https://www.podium.com/)**  
  Interaction management platform for local businesses. Features two-way SMS, review generation, webchat, and payment requests. Widely used by retail, healthcare, and service businesses.

- **[SlickText](https://www.slicktext.com/)**  
  SMS marketing platform with two-way texting, automation, and integrations. Features drip campaigns, keyword opt-ins, and CRM synchronization.

- **[Attentive](https://www.attentive.com/)**  
  AI-powered SMS and mobile marketing platform for e-commerce. Features personalized campaigns, two-way conversations, and revenue attribution.

- **[EZ Texting](https://www.eztexting.com/)**  
  SMS marketing and communication platform for businesses. Features mass texting, auto-replies, and team inbox for two-way conversations.

- **[SimpleTexting](https://simpletexting.com/)**  
  SMS marketing and texting service with two-way messaging, autoresponders, and integrations with CRMs and helpdesks.

- **[Birdeye](https://birdeye.com/)**  
  Reputation management and customer experience platform with two-way SMS, review requests, and messaging inbox.

- **[Klaviyo SMS](https://www.klaviyo.com/)**  
  SMS marketing integrated with Klaviyo's email and CDP platform. Features segmentation, automation, and two-way conversations for e-commerce.

- **[SMS Magic](https://www.sms-magic.com/)**  
  SMS integration for Salesforce, HubSpot, and Zoho. Features mass texting, two-way conversations, and CRM data synchronization.

## Open-Source GitHub Projects

- **[Chatwoot](https://github.com/chatwoot/chatwoot)**  
  Open-source customer engagement platform (MIT) with omnichannel inbox supporting SMS, WhatsApp, email, live chat, and social channels. Features agent assignment, canned responses, automation, and CRM integrations. 20k+ GitHub stars. Can be connected to Twilio, SMS gateways, and custom APIs for full conversational SMS capability.

- **[Rocket.Chat](https://github.com/RocketChat/Rocket.Chat)**  
  Open-source team communication platform (MIT) with omnichannel customer engagement features. Supports SMS via Twilio integration, WhatsApp, and live chat. Features bots, workflows, and extensive integrations. 40k+ GitHub stars.

- **[Zammad](https://github.com/zammad/zammad)**  
  Open-source helpdesk and customer support platform (AGPL-3.0) with SMS channel support. Features ticketing, live chat, telephony integration, and knowledge base. Can route SMS conversations to agents with full ticket management.

- **[Erxes](https://github.com/erxes/erxes)**  
  Open-source experience operating system (XOS) with plugin-based architecture. Includes Engage (email/SMS sequences), Inbox (omnichannel conversations), and CRM modules. Self-hosted with full data privacy.

- **[LiveHelperChat](https://github.com/LiveHelperChat/livehelperchat)**  
  Open-source live chat and messaging platform (Apache-2.0). Supports SMS via gateway integrations, WhatsApp, Telegram, and Facebook Messenger. Features chatbot, canned responses, and agent routing.

- **[Tiledesk](https://github.com/Tiledesk/tiledesk)**  
  Open-source conversational platform (MIT) with chatbot and live chat. Features WhatsApp, SMS, and Telegram integration through Twilio. Visual chatbot designer and human handoff.

- **[Typebot](https://github.com/baptisteArno/typebot.io)**  
  Open-source conversational forms and chatbot builder (AGPL-3.0). Features visual flow builder, integrations with WhatsApp, SMS, and messaging channels. Can be self-hosted with Docker.

- **[Botpress](https://github.com/botpress/botpress)**  
  Open-source conversational AI platform (MIT) for building chatbots. Features NLU, visual flow editor, and channel integrations including SMS, WhatsApp, and Messenger. 12k+ GitHub stars.

- **[Rasa](https://github.com/RasaHQ/rasa)**  
  Open-source conversational AI framework (Apache-2.0) for building contextual assistants. Features NLU, dialogue management, and channel connectors including SMS and WhatsApp. 18k+ GitHub stars.

- **[Twilio Open Source](https://github.com/twilio)**  
  Twilio maintains numerous open-source libraries including Twilio CLI, Serverless Toolkit, and helper libraries for SMS integration. These tools enable developers to build custom conversational SMS solutions on Twilio's infrastructure.

- **[SMS Gateway](https://github.com/ccall48/php-sms-gateway)**  
  Open-source PHP SMS gateway (license varies) for sending and receiving SMS via HTTP API. Can be integrated with open CRMs and helpdesks for conversational messaging.

- **[Kannel](https://github.com/kannel-sms/kannel)**  
  Open-source WAP and SMS gateway (BSD license). Features SMS push/pull, WAP push, and support for multiple protocols. Foundation for building custom SMS messaging infrastructure.

- **[PlaySMS](https://github.com/playsms/playsms)**  
  Open-source SMS management system (GPL-2.0) with web interface. Features bulk SMS, SMS gateway integration, and plugin architecture. Can be connected to open CRMs for conversational workflows.

### Additional Strong Open-Source Options

- **[Rocket.Chat Omnichannel](https://github.com/RocketChat/Rocket.Chat)** — SMS via Twilio, WhatsApp, and other channels with unified agent inbox.
- **[Papercups](https://github.com/papercups-io/papercups)** — Open-source customer messaging (MIT) with live chat and SMS integration.
- **[LibreChat](https://github.com/danny-avila/LibreChat)** — Open-source AI chat platform (MIT) with messaging channel integrations.
- **[Waha](https://github.com/devlikeapro/waha)** — Open-source WhatsApp HTTP API (Apache-2.0) for conversational messaging.
- **[Evolution API](https://github.com/EvolutionAPI/evolution-api)** — Open-source WhatsApp and messaging API (Apache-2.0) for multi-channel conversations.
- **[Baileys](https://github.com/WhiskeySockets/Baileys)** — Open-source WhatsApp Web API (MIT) for building custom messaging integrations.
- Community **n8n** workflows for SMS automation and conversational routing.
- **Grafana** and **Metabase** for messaging analytics dashboards.

**Frameworks for building custom systems**: Combine **Chatwoot** or **Zammad** as the omnichannel inbox with **Twilio** or **Kannel** for SMS gateway connectivity, **Typebot** or **Rasa** for conversational AI, and **PostgreSQL** for persistence — creating a fully self-hosted, enterprise-grade conversational SMS platform.
